# 🎓 Damanhour University – Smart Campus Portal (Frontend)

## Overview
A modern, responsive web portal serving Damanhour University students,
faculty, and staff. This is the **frontend phase** of the project.

## Tech Stack
- HTML5 (semantic)
- CSS3 (custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Font Awesome, Google Fonts, AOS

## Pages
1. `index.html` – Landing page (hero, features, services, events, contact)
2. `login.html` – Login with validation
3. `register.html` – Register with password strength meter
4. `dashboard.html` – Student dashboard

## Architecture
Modular CSS (`style` → `components` → `responsive`), modular JS
(`main`, `auth`, `dashboard`), clean naming conventions.

## How to Run
Open `index.html` in any modern browser. No build tools required.

## SDLC Coverage (Frontend Phase)
- ✅ Requirements: user stories for each feature
- ✅ Design: modular architecture + UML planned
- ✅ Implementation: clean, readable, documented code
- ✅ Testing: manual cross-browser + responsive testing
